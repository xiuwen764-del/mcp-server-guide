### 一、Figma MCP Server核心作用
Figma MCP（Model Context Protocol）服务器是衔接Figma设计平台与AI智能体的中间层，核心能力是将Figma文件中的设计系统、图层信息、样式规范、资源资产等上下文直接同步给AI，大幅提升AI从设计稿生成代码的还原度和准确性，无需手动导出/上传设计文件即可完成设计到开发的流程衔接。

### 二、工具分类与速率限制规则
1.  **受限工具（读取类）**：所有从Figma拉取数据的操作均受速率限制，包括但不限于：
    - 获取文件/页面/节点详情
    - 导出设计资源（图片、图标、组件）
    - 查询设计系统、样式库、组件属性
    - 获取评论、版本历史信息
2.  **免限制工具（写入类）**：向Figma写入数据的操作不受速率限制，包括但不限于：
    - 新建/修改图层、组件、样式
    - 添加评论、标记开发进度
    - 同步代码生成结果标注到设计稿

### 三、不同用户套餐的速率限制规则
| 用户套餐   | 速率限制标准                                  |
|------------|-----------------------------------------------|
| Starter    | 100次请求/每用户/每分钟                       |
| Professional | 500次请求/每用户/每分钟                      |
| Organization | 2000次请求/每用户/每分钟                     |
| Enterprise | 可联系Figma支持自定义调整速率限制阈值         |

### 四、快速配置与调用流程
1.  **安装认证**：在MCP客户端中添加Figma MCP服务器，使用你的Figma个人访问令牌（PAT）完成身份认证，令牌需要授予`files:read`、`files:write`等对应权限。
2.  **绑定设计文件**：输入需要处理的Figma文件链接，服务器自动解析文件权限，确认可访问后完成绑定。
3.  **AI调用示例**：你可以直接向AI发起指令："获取当前Figma文件首页的所有组件样式规范，生成对应的React TS代码，使用Tailwind CSS实现"，AI会自动调用MCP服务器拉取设计信息完成任务。
